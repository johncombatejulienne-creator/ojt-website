═══════════════════════════════════════════════════════════════
STEP 1: VERCEL DEPLOYMENT
═══════════════════════════════════════════════════════════════

□ Open PowerShell in project folder
□ Run: vercel login
□ Click the verification link in browser
□ Run: vercel
□ Enter project name: ojt-website-combate
□ Accept defaults
□ Wait for deployment

═══════════════════════════════════════════════════════════════
STEP 2: SUPABASE DATABASE
═══════════════════════════════════════════════════════════════

□ Go to: https://supabase.com
□ Sign up / Login
□ Click "New Project"
□ Name: ojt-website-combate
□ Create strong password
□ Region: Singapore
□ Wait 2-3 minutes for setup
□ Settings → Database → Connection String (URI)
□ Copy connection string
□ Replace [YOUR-PASSWORD] with actual password
□ SAVE THIS CONNECTION STRING!

═══════════════════════════════════════════════════════════════
STEP 3: GOOGLE OAUTH
═══════════════════════════════════════════════════════════════

□ Go to: https://console.cloud.google.com
□ Create new project: "OJT Website Combate"
□ APIs & Services → Library → Enable "Google+ API"
□ OAuth consent screen → External
□ Fill in app name and email
□ Credentials → Create OAuth Client ID
□ Type: Web application
□ Add redirect URIs:
  - http://localhost:3000/api/auth/callback/google
  - https://ojt-website-combate.vercel.app/api/auth/callback/google
□ Copy Client ID
□ Copy Client Secret
□ SAVE THESE!

═══════════════════════════════════════════════════════════════
STEP 4: ENVIRONMENT VARIABLES
═══════════════════════════════════════════════════════════════

Run these commands in PowerShell:

□ vercel env add DATABASE_URL
   → Paste Supabase connection string

□ vercel env add NEXTAUTH_SECRET
   → Generate at: https://generate-secret.vercel.app/32
   → Paste generated secret

□ vercel env add NEXTAUTH_URL
   → Type: https://ojt-website-combate.vercel.app

□ vercel env add GOOGLE_CLIENT_ID
   → Paste Google Client ID

□ vercel env add GOOGLE_CLIENT_SECRET
   → Paste Google Client Secret

═══════════════════════════════════════════════════════════════
STEP 5: PRODUCTION DEPLOY
═══════════════════════════════════════════════════════════════

□ Run: vercel --prod
□ Wait for deployment
□ Website is LIVE!

═══════════════════════════════════════════════════════════════
